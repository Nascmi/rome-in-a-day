# Roadmap

## Guiding Question

Does each new system make tomorrow’s attempt feel strategically and visibly different?

## Phase 1 — Reliability

- Save and resume an active run
- Persist sound, music, selected campaign, and selected plan
- Add explicit save-version migrations
- Add a reset-save confirmation screen
- Add automated tests for every campaign goal
- Add regression coverage for victory transitions

## Phase 2 — Construction Depth

- Introduce building prerequisites
- Add construction queues and build time
- Add builder professions: laborers, masons, engineers, haulers
- Add campaign-specific resource pressure
- Add limited building placement choices
- Add infrastructure adjacency or network bonuses
- Add repair, supply, or maintenance tradeoffs

## Phase 3 — Chapter Identity

### Rome

- Senate and political mandate objectives
- Population and housing pressure
- Monument placement milestones

### Italia

- Multiple settlements connected by roads
- Regional food distribution
- Frontier-defense requirements
- Terrain-specific construction penalties

### Mare Nostrum

- Ports connected through shipping lanes
- Fleet construction
- Lighthouse coverage
- Trade and piracy events

## Phase 4 — Empire Layer

- Province map
- Campaign selection by territory
- Province-specific modifiers
- Persistent imperial resources
- Expansion choices with opportunity costs
- Regional wonders
- Final “Build the Empire in a Day” objective

## Phase 5 — Presentation

- Purpose-built worker sprite animation
- Chapter-specific landscapes and skylines
- More construction stages
- Dedicated music themes per chapter
- Improved sunset and victory sequences
- PWA screenshots and full icon set
- Accessibility review for color, sound, motion, and touch targets

## Phase 6 — Product Readiness

- Tutorial and first-session guidance
- Local statistics and balance dashboard
- Optional privacy-respecting analytics
- Cross-device save strategy
- Error monitoring
- Automated deployment checks
- Playtesting program and structured feedback form

## Deliberately Deferred

- Advertising
- Loot boxes
- Randomized monetized rewards
- Multiplayer
- Accounts before cross-device saves are justified
- A large content expansion before the current three chapters are balanced
